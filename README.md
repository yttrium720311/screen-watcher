# 本地屏幕识别与固定坐标点击工具

Windows 10/11 的中文桌面程序。屏幕目标确认出现后，只点击预设的屏幕绝对坐标。目标移动不会改变点击坐标；目标持续存在，无论持续几秒还是几小时，都不会重复触发。

## 快速开始

1. **启动**：打开 `dist/ScreenWatch/ScreenWatch.exe`。必须保留同目录的 `_internal` 文件夹，不要单独复制 EXE。EXE 运行无需安装 Python，也不需要联网。
2. **目标**：点“导入目标图片”，或点“截取屏幕模板”，在冻结的桌面画面上拖动框选。按 Esc 取消。图片会另存到本软件的数据目录，不依赖原图片继续存在。
3. **检测区域**：推荐点“框选检测区域”，只选可能出现目标的区域。不勾选自定义区域时，逐一检测所有显示器，显示最高分数。自定义区域必须完全位于一块显示器内。
4. **固定坐标**：输入 X/Y，或点“鼠标选取坐标”，在冻结画面上单击需要的位置。这次选取只发生在遮罩窗口，不会点击背后的应用。负坐标有效，例如主屏左侧的显示器。
5. **先只监测**：保持“启用自动点击”未勾选，点“开始监测”。观察分数和状态，分别测试有目标、无目标的画面，调整阈值。运行时模板预览会隐藏，避免识别自身。
6. **启用自动点击**：勾选自动点击，核对确认框中的固定坐标和急停快捷键后确认。若目标已在仅监测模式确认出现，不会立即补点；需要目标消失后再次出现。也可以停止、启用自动点击、再开始一次新的监测。
7. **紧急停止**：默认全局快捷键 `Ctrl+Alt+F8`，或点击窗口底部红色停止按钮。快捷键可在界面修改并“应用”；注册失败会显示原因，未成功注册时不能启用自动点击或测试点击。

“测试点击”会真的操作鼠标，单独弹出确认框，并预留 3 秒准备时间，再加上设置的点击延迟。倒计时期间可急停取消。监测期间不允许测试点击或修改识别/坐标配置，须先停止。

## 启动源代码与重新打包

建议使用 Windows x64、Python 3.12。源码无须依赖本次开发电脑的 Python 路径。

- 双击 `run.bat`：首次自动建立 `.venv` 并安装 `requirements.txt`，然后运行。首次安装需要联网；之后运行不联网。
- 双击 `setup.bat`：安装或修复依赖。若 Windows 的 python 命令只是商店入口，请先安装真正的 Python 3.12 x64，并启用 Python Launcher 或加入 PATH。
- 双击 `test.bat`：执行自动化测试。测试使用模拟鼠标，不会真实点击桌面。
- 双击 `build.bat`：安装依赖、运行测试、用 PyInstaller 打包。测试失败时停止打包。产物在 `dist/ScreenWatch/`，请复制整个目录。

手动命令（在本项目目录执行）：

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe main.py
.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean ScreenWatch.spec
```

## 状态机与点击规则

| 状态 | 含义 |
| --- | --- |
| STOPPED | 已停止，不接受检测结果、不安排点击 |
| WAITING | 等待连续满足出现阈值 |
| DETECTED | 刚确认出现；本轮触发立即占用，最多安排一次点击 |
| WAITING_FOR_DISAPPEARANCE | 已占用，等待连续低于消失阈值 |

出现条件是 `分数 ≥ 出现阈值` 连续 N 次；消失条件是 `分数 < 消失阈值` 连续 M 次。中间分数会打断消失计数，保留已经占用的状态。出现/消失必须连续确认，截图或识别异常会打断连续计数，但不会把目标视为消失。

触发状态在执行点击前已经占用，线程锁保证同一出现事件只能安排一次。一个后台线程负责截图、匹配、延迟调度、鼠标操作；GUI 只读取状态快照，鼠标调用不占用 GUI 状态锁。没有无限点击队列，也没有固定冷却时间。

- 启动时目标已经存在：正常确认并触发一次。
- 仅监测模式仍然推进状态机。重新启用点击不会对已经占用的目标补点。
- 暂停：取消尚未执行的点击，保留当前触发状态；继续后需要正常消失/出现才能重新触发。
- 停止：关闭自动点击、取消延迟任务；再次开始属于新的监测会话，当前已有目标可以触发一次。
- 目标在点击延迟内确认消失：取消这次点击，不追赶已经消失的目标。
- 截图失败：记录错误、取消延迟点击、保留触发状态，按检测间隔继续尝试截图。连续相同错误只记录一次，恢复时记录恢复信息。
- 鼠标失败：记录错误、关闭自动点击、本轮不重试。Windows 拒绝输入时不尝试提权或绕过权限。
- 急停会取消尚未提交的鼠标操作；已经提交给 Windows 的一次输入无法撤回。双击中途急停可以取消第二下。不要将本工具用于必须保证零延迟停止的安全关键操作。
- 关闭窗口会先取消点击，再等待线程结束；不会留下独立后台鼠标进程。

## 长时间等待与资源使用

默认检测间隔 **300 ms**，出现确认 **2 次**，消失确认 **3 次**，出现阈值 **0.90**，消失阈值 **0.80**。这些是起点，需按实际图像验证。

推荐长期监测使用局部区域、200–500 ms 间隔、具有独特颜色/文字/边缘的小模板。检测间隔是每次截图识别结束后到下一次检测之间的等待时间，实际周期还包含截图和匹配耗时。间隔越短，响应越快但 CPU 占用越高；间隔越长越省资源，但短暂出现的目标可能被漏掉。300 ms、出现 2 次时，理想确认延迟约 300–600 ms，再加处理耗时及可选点击延迟。

**点击间隔不设定**，完全由实际的消失、再次出现决定。8–9 分钟没出现不会停止；出现后持续 30 分钟也不会因计时而重新点击。线程通过事件等待休眠，无忙等待。日志窗口最多保留 500 行，后台日志队列最多 100 条，磁盘日志约 1 MB 一份，最多保留当前文件和 3 份备份。截图与匹配结果不积累、不持续写盘。

界面显示本轮监测时长（含暂停时间）、距上次点击的时间、本次打开软件累计点击动作数、出现/消失/点击时间、最高匹配分数、截图/识别成功状态。单击和双击各计为一次动作；统计不跨软件重启保存。测试点击单独写日志，不计入监测触发次数。

## 识别、显示缩放与多屏限制

- 第一版采用 OpenCV 彩色模板匹配 `1 - TM_SQDIFF_NORMED`，纯黑模板采用平方差特例避免零分母。分数不是概率。建议选择具有辨识度的图块，不要选择大块纯色；阈值高可以减少误识别，但过高会漏报。
- 不自动缩放模板，不识别旋转和复杂动画。分辨率、显示缩放、浏览器缩放、主题、抗锯齿变化后需要重新截取模板。动画应选稳定区域。
- 采用 Windows Per-Monitor V2 DPI 感知；框选坐标由各屏截图的实际像素换算。原生显示器矩形用于关联 Qt 和 MSS，避免设备名和屏幕型号不一致。
- 自定义框选不跨显示器；全屏模式逐屏检测。跨两块屏幕显示的目标不能作为一个完整模板匹配。屏幕之间的空洞不是有效点击位置。
- 点击前校验显示器坐标，双击两下都使用固定配置坐标。Windows 使用 `SendInput` 将绝对移动和按下/释放批量提交，保留 PyAutoGUI 的安全角落检查。采用原生输入是为了检查输入提交失败及处理虚拟桌面坐标；并非点击目标匹配位置。
- 显示器热插拔、方向或分辨率改变后，请停止、重新设置区域和坐标，再开始。仅检测当前可见桌面，最小化的目标窗口、被遮挡的画面、锁屏、休眠、远程会话断开或受保护画面不保证可识别。建议锁屏/休眠前停止；软件不会修改系统电源设置。
- 目标程序可能拒绝合成输入；统计表示成功向系统提交动作，不表示目标软件一定接受。程序不绕过 UAC、安全桌面或反作弊机制。
- 推荐将本工具最小化或移出检测区域，防止工具窗口挡住目标。默认左上角 (0,0) 只是初始值，请自行选取实际点击位置。

Windows 输入行为依据：[SendInput 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)、[MOUSEINPUT 虚拟桌面坐标](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-mouseinput)。

## 配置、日志与隐私

普通运行的数据目录为 `%LOCALAPPDATA%\ScreenWatchLocal`：

- `config.json`：阈值、坐标、区域、模板路径、延迟及快捷键。
- `templates/`：用户导入或截取的目标模板，每次设置保存一张新图，不覆盖旧图。
- `screenwatch.log` 和轮转备份：状态变化、点击和错误，不保存完整桌面截图。

自动点击开关从不保存，重启后始终关闭。配置缺失或损坏会使用默认值并显示提示。删除不用的旧模板前，确认它不是当前配置所引用的模板。程序运行不使用网络、云服务、数据库、摄像头或麦克风。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| main.py / ui.py | DPI 初始化、异常停止、中文 GUI 和交互 |
| state_machine.py | 纯逻辑出现/消失状态机，无时间冷却依赖 |
| engine.py | 单线程后台监测、可取消延迟点击、快照与有界日志 |
| detector.py | MSS 截图、模板匹配、屏幕/区域校验 |
| click_controller.py / windows_mouse.py | 固定坐标输入和错误处理 |
| selection.py | 后台截图、各屏幕冻结框选、物理坐标换算 |
| hotkey.py | Windows 全局急停快捷键注册与释放 |
| config.py | 配置校验、默认值、原子保存 |
| tests/ | 模拟检测/时钟/鼠标、GUI 控件与坐标换算测试 |
| smoke_test.py | 真实截图与短时 GUI 检查，不操作鼠标 |

开发时运行 `python smoke_test.py <检查输出目录>` 可复现真实截图和界面启动检查。它会显示窗口约 4 秒、注册急停、仅监测局部区域，保存软件窗口图片与 JSON 结果；不保存完整桌面截图。若默认急停快捷键已被本工具另一个实例占用，请先关闭那个实例。

打包请使用附带的 `ScreenWatch.spec`，它排除开发机 PATH 中可能混入的同名第三方 ICU DLL，使用 Windows 自带 ICU，避免 QtWidgets 加载错误。

详细验证结果与尚未验证的环境见 `TEST_RESULTS.md`。
